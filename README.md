## 📌 Project Description

A Java-based Hotel Management System designed to simplify hotel operations
through room, guest, booking, billing, and reporting modules. The application
uses object-oriented programming, file handling, input validation, and
CSV-based data persistence. It provides a simple console interface for
managing hotel information efficiently while demonstrating practical Java
programming concepts and modular software design.

🖥️ Application Modules
```
1. Room Management

Allows the user to manage hotel rooms and check room availability.

2. Guest Management

Allows hotel staff to register and manage guest information.

3. Booking Management

Allows users to create and cancel hotel reservations.

4. Billing

Calculates room charges, service charges, tax, and the final bill.

5. Dashboard

Displays hotel occupancy and room availability information.

6. Reports

Provides useful information about hotel operations.
```
